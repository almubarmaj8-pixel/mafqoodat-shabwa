تفعيل قاعدة البيانات المشتركة

اجعل إعلانات منصتك مشتركة بين كل المستخدمين ومتزامنة لحظياً — عبر Firebase Firestore المجاني.

← العودة إلى المنصة
✅ الخطة المجانية (Spark) تكفي تماماً لمنصة محلية: 50 ألف قراءة و20 ألف كتابة يومياً، و1 جيجابايت تخزين.

1 إنشاء المشروع

  1. افتح console.firebase.google.com وسجّل الدخول بحساب Google.
  2. اضغط Create project وسمِّه مثلاً mafqoodat-shabwa.
  3. أكمل الخطوات (يمكنك إلغاء تفعيل Google Analytics).

2 تفعيل تسجيل الدخول المجهول

  1. من القائمة الجانبية: Build ← Authentication ← تبويب Sign-in method.
  2. اضغط Add new provider واختر Anonymous ثم Enable وSave.
⚠️ هذه الخطوة ضرورية: بدونها لن يستطيع أي مستخدم نشر أو تعديل إعلاناته، لأن قواعد الأمان تمنع الكتابة من غير المسجّلين.

3 إنشاء قاعدة البيانات

  1. من القائمة الجانبية: Build ← Firestore Database ← Create database.
  2. اختر Start in production mode (القواعد الآمنة) ثم اختر أقرب منطقة، مثل eur3 أو me-central1 إن ظهرت.
  3. انتظر حتى تظهر قاعدة البيانات.

4 ضبط قواعد الأمان

افتح تبويب Rules داخل Firestore، امسح كل شيء، والصق هذا النص ثم اضغط Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function signedIn() { return request.auth != null; }
    function isString(v, minLen, maxLen) {
      return v is string && v.size() >= minLen && v.size() <= maxLen;
    }
    function validPost(d) {
      return d.keys().hasOnly(['id','type','title','description','category','location',
                'contactName','contactPhone','contactPref','images','thumbs','image',
                'status','date','eventDate','returnedDate','views','ownerId'])
        && d.type in ['missing','found']
        && d.status in ['active','returned']
        && isString(d.title, 4, 90)
        && isString(d.description, 12, 700)
        && isString(d.category, 1, 30)
        && isString(d.location, 2, 70)
        && isString(d.contactName, 2, 45)
        && isString(d.contactPhone, 7, 20)
        && (!('images' in d) || (d.images is list && d.images.size() <= 3))
        && (!('thumbs' in d) || (d.thumbs is list && d.thumbs.size() <= 3))
        && (!('views' in d) || (d.views is int && d.views >= 0));
    }

    match /posts/{postId} {
      allow read: if true;
      allow create: if signedIn()
        && validPost(request.resource.data)
        && request.resource.data.ownerId == request.auth.uid
        && request.resource.data.status == 'active'
        && request.resource.data.views == 0;
      allow update: if signedIn()
        && resource.data.ownerId == request.auth.uid
        && request.resource.data.ownerId == resource.data.ownerId
        && validPost(request.resource.data);
      allow delete: if signedIn() && resource.data.ownerId == request.auth.uid;
    }

    // عدّاد المشاهدات: زيادة بمقدار 1 فقط
    match /posts/{postId} {
      allow update: if signedIn()
        && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['views'])
        && request.resource.data.views == resource.data.views + 1;
    }

    match /reports/{reportId} {
      allow create: if signedIn();
      allow read, update, delete: if false;
    }

    match /{document=**} { allow read, write: if false; }
  }
}
🚫 لا تستخدم allow read, write: if true; في الإنتاج — أي شخص سيستطيع حذف كل الإعلانات.

5 نسخ بيانات التطبيق

  1. اضغط ⚙️ Project settings ← تبويب General ← انزل إلى Your apps.
  2. اضغط أيقونة الويب </>، سمِّ التطبيق ثم Register app.
  3. سيظهر كائن firebaseConfig — انسخ القيم.

6 لصق القيم في الموقع

افتح ملف firebase-config.js في مشروعك واستبدل القيم:

const FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "mafqoodat-shabwa.firebaseapp.com",
  projectId: "mafqoodat-shabwa",
  storageBucket: "mafqoodat-shabwa.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef123456",
  useAnonymousAuth: true
};

ثم ارفع الملف إلى GitHub (أو احفظه محلياً) وأعد تحميل الصفحة. سيظهر في أعلى المنصة شارة مزامنة مباشرة بدل تنبيه «وضع محلي».

7 التحقق والإدارة

ما تريد معرفتهكيف
هل المزامنة تعمل؟افتح المنصة من جهازين، أضف إعلاناً من الأول ولاحظ ظهوره فوراً في الثاني.
الإعلانات المنشورةFirestore Database ← تبويب Data ← مجموعة posts.
البلاغاتمجموعة reports — راجعها واحذف الإعلان المخالف من مجموعة posts.
حذف إعلان مخالفافتح الإعلان في Firestore واضغط ⋮ ← Delete document.
الفهارس (Indexes)إن ظهر خطأ عن فهرس مطلوب، اضغط الرابط في رسالة الخطأ لإنشائه تلقائياً.
📌 ملاحظة مهمة: المستخدم المحدود يُخزَّن في المتصفح، لذا الإعلان الذي أضفته من جهاز يظهر كـ«إعلانك» على ذلك الجهاز فقط، ويمكنك تعديله وحذفه من هناك.
