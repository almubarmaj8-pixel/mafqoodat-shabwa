# مفقودات شبوة 🔍

تطبيق ويب للإعلان عن المفقودات والموجودات بدلاً من مجموعات الواتساب وغيرها.

## المميزات ✨

- **نوعان من الإعلانات**: مفقود (شيء فقدته) أو موجود (شيء وجدته وتريد إرجاعه)
- **تصنيفات متنوعة**: هواتف، مستندات، محافظ ونقود، مجوهرات، مفاتيح، ملابس، إلكترونيات، حيوانات، وتصنيف مخصص
- **بحث وفلترة فورية**: ابحث بالاسم أو الوصف أو المكان
- **رفع صور**: أضف صورة للشيء المفقود أو الموجود
- **اتصال مباشر**: تواصل مع صاحب الإعلان بضغطة زر
- **تتبع الحالة**: علّم الإعلان "تم الإرجاع" عند استرجاع المفقود
- **حفظ تلقائي**: البيانات تُحفظ محلياً في المتصفح (localStorage)
- **تصميم عربي RTL** عصري وسلس، متجاوب مع الجوال والحاسوب

## كيفية الاستخدام 🚀

1. افتح `index.html` في أي متصفح
2. اضغط "إضافة إعلان" لإنشاء إعلان جديد
3. اختر النوع (مفقود/موجود)، املأ التفاصيل، واضغط "نشر"
4. تصفح الإعلانات وابحث عن ما تريد
5. تواصل مع أصحاب الإعلانات مباشرة

3. انشره على GitHub Pages أو أي خدمة استضافة ثابتة
