# مفقودات شبوة 🔍

منصة ويب خفيفة (PWA) للإعلان عن **المفقودات والموجودات** في محافظة شبوة — بديل منظّم وآمن لمجموعات الواتساب.

> 🌐 **الموقع المباشر:** <https://almubarmaj8-pixel.github.io/mafqoodat-shabwa/>

---

## ✨ المميزات

### للمستخدم
- **إعلانان في نموذج واحد:** «مفقود» (فقدت شيئاً) و«موجود» (وجدت شيئاً وأريد إرجاعه).
- **نشر بدون تسجيل:** لا حساب ولا رقم سري — اضغط، اكتب، انشر في أقل من دقيقة.
- **صور ذكية:** حتى 3 صور، تُضغط تلقائياً على جهاز المستخدم (1280px / JPEG) لتوفير بيانات الجوال.
- **بحث عربي ذكي:** يتجاهل الهمزات والتشكيل (أ/إ/آ = ا، ة = ه، ى = ي) والأرقام العربية، ويدعم البحث بعدة كلمات مع ترتيب النتائج بحسب الصلة.
- **فلاتر وترتيب:** حسب النوع (مفقود/موجود/تم الإرجاع)، التصنيف، والأحدث/الأقدم/الأكثر مشاهدة — وكل حالة محفوظة في الرابط ليمكن مشاركتها.
- **تواصل فوري:** واتساب برسالة جاهزة تتضمّن رابط الإعلان، اتصال مباشر، ونسخ الرقم (مع إخفاء جزئي للرقم حتى يضغط «إظهار»).
- **مشاركة الإعلان:** عبر واجهة المشاركة في النظام أو بنسخ الرابط، مع رابط مباشر لكل إعلان.
- **إعلاناتي:** تعديل، تعليم «تم الإرجاع»، أو حذف — من الجهاز الذي أُنشئ منه الإعلان فقط.
- **إبلاغ عن الإعلانات المخالفة** (يُخزَّن في مجموعة `reports` عند تفعيل Firebase).
- **وضع ليلي/نهاري** + احترام إعداد النظام، وواجهة عربية RTL بالكامل.
- **يعمل دون إنترنت (PWA):** يمكن تثبيته على الجوال، ويُظهر آخر الإعلانات المحفوظة عند انقطاع الشبكة.

### للمطوّر
- **بدون أي أدوات بناء:** HTML + CSS + JavaScript فقط، بدون npm أو خطوة تجميع.
- **Firebase اختياري:** يعمل التطبيق بالكامل بوضع محلي (localStorage)، وعند إضافة مفاتيح Firebase يتحول لمزامنة لحظية بين كل المستخدمين.
- **تحميل تدريجي:** 24 إعلاناً في الدفعة الواحدة (`PAGE_SIZE`) ليبقى الأداء ثابتاً مع مئات الإعلانات.
- **أمان:** قواعد Firestore جاهزة (تسجيل مجهول + منع تعديل إعلانات الآخرين) وتهيئة النصوص ضد XSS.
- **أداء:** لا صور خارجية إطلاقاً (كل الخلفيات CSS)، وتحميل Firebase بشكل مؤجّل عند الحاجة فقط.
- **إتاحة:** تنقل بلوحة المفاتيح، حصر التركيز داخل النوافذ، سمات ARIA، واحترام `prefers-reduced-motion`.

## 🚀 التشغيل محلياً

الموقع ملفات ثابتة، يمكن فتحه بالنقر المزدوج على `index.html`، لكن يُفضّل تشغيل خادم محلي
(لأن Service Worker يعمل عبر `https` أو `localhost` فقط):

```bash
# Python
python3 -m http.server 8000

# أو Node
npx serve .
```

ثم افتح: <http://localhost:8000>

**وضع العرض (بيانات تجريبية):** أضف `?demo=1` إلى الرابط → `http://localhost:8000/?demo=1`

## 🔗 تفعيل قاعدة البيانات المشتركة (Firebase)

بدون تفعيل Firebase يعمل التطبيق **بوضع محلي فقط**: الإعلان يُحفظ على جهاز صاحبه ولا يراه غيره.
لجعل الإعلانات مشتركة ومتزامنة لحظياً بين الجميع:

1. اتبع الدليل المرفق: افتح [`FIREBASE-SETUP.html`](FIREBASE-SETUP.html) (أو شغّل الموقع واضغط زر «طريقة التفعيل»).
2. المختصر: أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com) → فعّل
   **Authentication ← Anonymous** → أنشئ **Firestore Database** → انسخ محتوى `firestore.rules` إلى تبويب Rules → الصق مفاتيح الويب في `firebase-config.js`.

```js
// firebase-config.js
const FIREBASE_CONFIG = {
  apiKey: "AIza…",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
  useAnonymousAuth: true   // مهمة للحماية: كل جهاز يملك إعلاناته فقط
};
```

> الخطة المجانية (Spark) كافية تماماً: 50 ألف قراءة و20 ألف كتابة يومياً.

## 🌍 النشر على GitHub Pages

1. ارفع الملفات إلى فرع `main`.
2. من المستودع: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. سيظهر الموقع على `https://<username>.github.io/<repo>/`.

> لا تنسَ تحديث الرابط في `sitemap.xml` و`robots.txt` ووسوم `og:` في `index.html` إن غيّرت اسم المستودع.

## ⚙️ تخصيص سريع

| ما تريد تغييره | المكان |
|---|---|
| الألوان والوضع الليلي | متغيرات `:root` في أعلى `style.css` |
| التصنيفات وأيقوناتها | `CAT_ICONS` في `script.js` + قائمة `#fCategory` في `index.html` |
| عدد الإعلانات في الدفعة | `PAGE_SIZE` في `script.js` |
| حجم/جودة الصور | كائن `IMG` في `script.js` |
| نصوص الصفحة الرئيسية | قسم `.hero` في `index.html` |

## 🔐 الخصوصية

- لا تتبّع، ولا إعلانات، ولا تسجيل دخول.

- الإعدادات و«إعلاناتي» تُخزَّن محلياً في متصفح المستخدم.
